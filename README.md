# 🧮 Calculadora de IMC (Índice de Masa Corporal)

Este proyecto es una calculadora simple de IMC desarrollada con **HTML**, **CSS** y **JavaScript**. Permite a los usuarios ingresar su peso y estatura para calcular su índice de masa corporal y mostrar su clasificación (bajo peso, normal, sobrepeso u obesidad), junto con una imagen ilustrativa.

---

## 📋 Características

- Cálculo del IMC usando la fórmula estándar.
- Clasificación del resultado en rangos (bajo, normal, sobrepeso, obesidad).
- Mensajes personalizados basados en el resultado.
- Limpieza de formulario con el botón "Nuevo".
- Visualización de imágenes según el estado del IMC.
